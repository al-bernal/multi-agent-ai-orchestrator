# multi-agent-ai-orchestrator
Multi-agent AI orchestration workflow built using OpenAI Agents, dynamic routing, MCP integrations and retrieval-augmented generation techniques.

# Features

- Dynamic intent classification
- Multi-agent orchestration
- Web research capabilities
- Local document retrieval
- Google Drive MCP integration
- Conversational state management
- Response summarization layer
- Retrieval-Augmented Generation (RAG)


## Architecture

User Request
    ↓
Intent Classification Layer
    ↓
Multi-Agent Routing
 ├── Web Research Agent
 ├── Local Knowledge Agent
 ├── Google Drive Retrieval Agent
 └── General AI Assistant
    ↓
State Management Layer
    ↓
Summarization Layer
    ↓
Final Response


## Tech Stack

- OpenAI Agents
- MCP Integrations
- Google Drive API
- Retrieval-Augmented Generation (RAG)
- GPT-4.1 / GPT-4o
- Workflow Orchestration
